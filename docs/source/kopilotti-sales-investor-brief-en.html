01

PROBLEM

Negotiation interrupts the digital journey

Search, finance and checkout can be digital, yet price progression often still waits for a salesperson or trade-in manager.

02

PRODUCT

A bounded digital negotiation path

Vehicle-specific entry, controlled offer rounds and deterministic outcomes. Cases outside the boundary go to a person.

03

WHY DIFFERENT

AI without pricing authority

Natural-language interaction can move fast without delegating margin decisions to a model. The dealer defines the rules; software applies them.

EVIDENCE BEFORE CLAIMS

What the repositories support today

Technical evidence is kept separate from future direction. Implemented, tested and visible in the public demonstrator are not treated as interchangeable claims.

Kopilotti Sales
PUBLIC DEMONSTRATOR

The negotiation core is public

Magic Link and dealer-defined deterministic policy are live in the demonstrator. The current public path ends at an agreed price and handoff to the dealer's own completion process.

PERSISTENCE & ISOLATION

Server-side state is implemented

PostgreSQL negotiation persistence, tenant-scoped access, and schema/readiness gates are implemented and tested. This is not a broad production-ready claim for the entire product.

DEALER TOOLING

The Admin path is a real implementation

Dealer Admin includes a generic CSV/DMS-export import flow with validation, dry-run preview, human approval and atomic apply. No live vendor-specific DMS connection is claimed.

BLACK-BOX EVALUATION

Independent behavior checks exist

A separate HTTP/API harness runs live scenarios against pinned local Sales and disposable PostgreSQL. Targeting fails closed to non-production and evidence is redacted.

CURRENT BOUNDARIES

Boundaries we do not blur

  • No broad production-ready claim.
  • No active VIS / Autovista or carVertical production integration or announced partnership.
  • No live DDN verification on the public production path.
  • Kopilotti does not receive customer funds or make financing decisions.

NEXT MILESTONE

A controlled dealer pilot using vehicle-specific negotiation links. Deeper integrations follow only after the operating model has demonstrated measurable value.
